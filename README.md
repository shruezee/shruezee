## 🧭 How I build

- **Accessibility first.** Dynamic Type, VoiceOver, Voice Control, large tap targets, and never colour alone.
- **Kind UX.** Plain language, no guilt, no dark patterns, and designs tested with the people who'll use them.
- **Private by default.** No tracking, data stays on the device, and privacy manifests are done properly.
- **Shipped, not just built.** TestFlight, App Store review, privacy policies, and listings, end to end.
